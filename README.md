# EVA Noctis

Twenty-three vivid color themes inspired by the Evangelion units of the *Rebuild* films, the MAGI supercomputer interface, NERV, SEELE, the A.T. Field, Instrumentality, Terminal Dogma, the Angels and light counterparts of the main units, built on top of the excellent [Noctis](https://github.com/liviuschera/noctis) theme family by Liviu Schera.

Noctis is loved for its carefully balanced syntax highlighting and clear diagnostics. EVA Noctis keeps that structure and swaps in bold, saturated palettes: neon greens against deep violets, warning-sign oranges over near-black reds, and crisp sky blues for a daylight option.

## High contrast themes

`Noctis (NERV High Contrast)` and `Noctis (EVA Mark.06 High Contrast)` use pure black or pure white backgrounds, syntax colors with at least **7:1** contrast (WCAG AAA), and strong borders around focused and active elements. They are registered as VS Code high contrast themes, so they are also offered automatically when you enable a high contrast color mode in your operating system.

## Highlights

- **Derived from Noctis.** Every UI color, token color, diagnostic and Git decoration was remapped from the Noctis and Noctis Lux base themes, so nothing is left half-styled.
- **Readable by design.** Syntax text has at least 4.5:1 contrast against the editor background (comments at least 4:1). Errors and warnings are adjusted the same way.
- **Vibrant, not noisy.** Strong accents are reserved for the things that matter: the cursor, the active tab border, the status bar, keywords and strings.
- **Matching terminal colors.** Each theme defines all 16 ANSI colors for the integrated terminal, so `ls`, `git` and compiler output pick up the same palette.
- **Light and dark pairs.** Use `Noctis (EVA-01)` and `Noctis (EVA-00)` as a natural dark/light duo.

## Install

1. Open the Extensions view (`Ctrl+Shift+X` / `Cmd+Shift+X`).
2. Search for **EVA Noctis** and click **Install**.
3. Open the theme picker with `Ctrl+K Ctrl+T` (`Cmd+K Cmd+T` on macOS) and choose one of the `Noctis (EVA-NN)` themes.

From the command line:

```bash
code --install-extension RavenEibu.eva-noctis
```

## Follow your system appearance

To switch automatically between a dark and a light theme, add this to your `settings.json`:

```json
"window.autoDetectColorScheme": true,
"workbench.preferredDarkColorTheme": "Noctis (EVA-01)",
"workbench.preferredLightColorTheme": "Noctis (EVA-00)"
```

## Tweaking a theme

You can override any color without forking the theme. For example, to change the cursor color in EVA-01 only:

```json
"workbench.colorCustomizations": {
  "[Noctis (EVA-01)]": {
    "editorCursor.foreground": "#ff4fd8"
  }
}
```

Syntax colors can be adjusted the same way with `editor.tokenColorCustomizations`.

## Terminal themes (kitty and Ghostty)

The same palettes are available as [kitty](https://sw.kovidgoyal.net/kitty/) and [Ghostty](https://ghostty.org/) themes in the [`terminals`](terminals) folder of the repository (also bundled inside the extension). Each one defines the background, foreground, cursor, selection, tabs (kitty) and the 16 ANSI colors, so your terminal matches your editor.

**One-line installer** (Linux and macOS). It finds kitty and/or Ghostty, copies every theme and, with `--apply`, activates EVA-01 for dark mode and EVA-00 for light mode:

```bash
curl -fsSL https://raw.githubusercontent.com/RavenEibu/eva-noctis/main/terminals/install.sh | bash -s -- --apply
```

Options: `--dark EVA-13 --light EVA-01-Light` to choose the pair, `--kitty` / `--ghostty` for a single terminal, `--list` to see the themes and `--uninstall` to remove them. Existing configs are backed up as `*.pre-eva-noctis`. The same script is bundled with the extension, so you can also run it from the install folder: `bash ~/.vscode/extensions/raveneibu.eva-noctis-*/terminals/install.sh --apply`.

**Manual install: kitty**

```bash
mkdir -p ~/.config/kitty/themes
cp terminals/kitty/themes/*.conf ~/.config/kitty/themes/
```

Pick one with `kitten themes` (they appear under *Custom*), or add a line such as `include themes/Noctis-EVA-01.conf` to `kitty.conf`. To follow the system appearance, copy a dark and a light theme to `~/.config/kitty/dark-theme.auto.conf` and `light-theme.auto.conf`.

**Manual install: Ghostty**

```bash
mkdir -p ~/.config/ghostty/themes
cp terminals/ghostty/themes/* ~/.config/ghostty/themes/
```

Then set, for example, `theme = light:Noctis-EVA-00,dark:Noctis-EVA-01` in `~/.config/ghostty/config`.

Theme file names follow the pattern `Noctis-EVA-01`, `Noctis-EVA-01-Berserk`, `Noctis-MAGI`, `Noctis-NERV-HC`, and so on.

## Development

Themes are generated from the Noctis base themes by a small script, so a palette change is one edit and a rebuild:

```bash
git clone https://github.com/liviuschera/Noctis.git ../noctis-src
python3 scripts/build.py ../noctis-src/themes      # themes/*.json
python3 scripts/terminals.py ../noctis-src/themes  # terminals/kitty and terminals/ghostty
python3 scripts/screenshots.py                     # images/*.png (needs Playwright)
python3 scripts/package.py                         # eva-noctis-<version>.vsix
```

Palettes live in `scripts/build.py`. Every text color is adjusted automatically to meet its contrast target (4.5:1, or 7:1 for the high contrast themes).

## Feedback

Colors are a matter of taste, and the palettes are a loose interpretation of each unit rather than an exact match. If a color looks off or a language is hard to read, please [open an issue](https://github.com/RavenEibu/eva-noctis/issues) or leave a review on the Marketplace with a short code sample and the theme name.
